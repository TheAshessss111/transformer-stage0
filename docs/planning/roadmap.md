# 开发路线图：Stage Zero

> **策略**：垂直切片优先（D-15）。M0 用 Step 0.3 softmax 把全链路打通，拿到一个真正可用的页面；
> M1–M4 横向复制到其余四个 Step，每个里程碑独立可交付；M5 打磨发布。
>
> **编号**：`M<里程碑>` → `E<epic>` → `F<功能>`。每个功能有明确的完成定义（DoD）。

```
M0  地基 + 垂直切片（Step 0.3 softmax）        ██████████████████  最大的一块
 ↓
M1  Step 0.1 形状代数        ─┐
M2  Step 0.2 矩阵微积分       ├─ 可并行 / 可乱序，取决于你的学习进度
M3  Step 0.4 LayerNorm       │
M4  Step 0.5 数值稳定性      ─┘
 ↓
M5  打磨与发布
```

**依赖**：M0 必须先完成（它建立了全部基础设施）。M1–M4 之间无依赖。M5 依赖全部。
